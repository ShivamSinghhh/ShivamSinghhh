Full Stack Developer with 5 years of experience building web applications and production-ready agentic AI systems. I work end to end: responsive React and TypeScript frontends, Python (FastAPI) and Node.js backends, and PostgreSQL underneath.

My focus is agentic AI: agents that call tools, hand work to each other, retrieve the right context with RAG, and keep a human in the loop where it matters. I care about the parts that make them reliable in production: tests, guardrails, tracing and clean APIs.
